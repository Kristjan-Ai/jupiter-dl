# jupiter-dl
Uses the **yt-dlp python library** to download media from jupiter.err.ee and lasteekraan.err.ee

The main purpose of this project is to enable downloads of **series by season or episode** and using the metadata available at `https://services.err.ee/api/v2/vodContent/getContentPageData?contentId=<media id>`
